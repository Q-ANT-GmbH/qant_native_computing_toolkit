# C API documentation (Doxygen)

`./gen_doxydoc.sh` renders the C API documentation to `build/html`.

Requires the dependencies listed in `REPO_ROOT/environment.yml` and the `doxygen-latex` debian package, see
[CONTRIBUTING.md](../../CONTRIBUTING.md).

## Latex

A LaTeX installation is required as well. The headers document formulas with `@f$ … @f$` and `@f[ … @f]`.
Each formula is rendered by latex, requiring the `doxygen-latex` package.

## Stylesheets

Three stylesheets are loaded, in this order — each overriding the previous one:

| File | Origin |
| --- | --- |
| `doxygen.css` | generated by Doxygen itself, **do not edit** |
| `doxygen-awesome.css` | copied verbatim from upstream, **do not edit** |
| `doxygen-awesome-custom.css` | our own overrides |

Put every customisation in `doxygen-awesome-custom.css` to avoid conflicts when the doxygen version gets updated.

## Upgrading

1. Pick the newest Doxygen available on conda-forge and update the pin in `environment.yml`.
2. Migrate the configuration in `Doxyfile`. Beware of renamd/added/removed tags.
3. Update the doxygen-awesome theme to its newest release that is compatible with the Doxygen version.
4. Re-check the theme's required settings survived the migration.
